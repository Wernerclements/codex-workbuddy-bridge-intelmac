# 版本兼容

| 环境 | 应用版本 | 验证情况 | 可部署完整桥接器 |
| --- | --- | --- | --- |
| Intel Mac，macOS 26.5.1 | WorkBuddy 5.6.2，sidecar 协议 6 | 真实文本、文件、权限、取消、故障恢复通过 | 开发版 alpha，可本机使用 |
| Windows | 上游项目目标平台 | 本项目未进行 Windows 真实桌面测试 | 未确认 |
| Apple Silicon / 其他 macOS 或 WorkBuddy 版本 | 未测试 | 未验证 | 未确认 |

`reference/upstream/` 保留 Windows 原始实现，不属于本项目已支持的平台承诺。

## 更新验证顺序

1. 记录应用版本与 CPU 架构。
2. 执行只读诊断，确认协议、实例和认证可用。
3. 执行全部单元测试。
4. 在独立任务目录完成真实任务、取消与文件结果验收。
5. 更新本表并保留脱敏测试报告后，才声明支持该版本。

## 当前边界

- 使用 WorkBuddy 应用内置运行时和用户配置目录；没有新配模型 API。用户已核对两种主力模型的账号用量，四次任务合计 2.26 积分，使用端显示 CLI。
- 桥接器保存自己的任务记录；没有外接高层桌面会话注册，也不会自动继承任意专家或旧会话。
- 真实失联验收终止的是本项目 worker，未退出用户整个 WorkBuddy 桌面应用。整体应用退出和更新后的行为需要单独验收。
- WorkBuddy 更新后未知版本默认拒绝发出任务；先诊断、适配再更新支持表。
