# 版本兼容

| 环境 | 应用版本 | 验证情况 | 可部署完整桥接器 |
| --- | --- | --- | --- |
| Intel Mac，macOS 26.5.1 | WorkBuddy 5.6.2，sidecar 协议 6 | 只读发现、认证、结构检查通过；补丁单元测试通过 | 否，适配器待实现 |
| Windows | 上游项目目标平台 | 本项目未进行 Windows 真实桌面测试 | 未确认 |
| Apple Silicon / 其他 macOS 或 WorkBuddy 版本 | 未测试 | 未验证 | 未确认 |

`reference/upstream/` 保留 Windows 原始实现，不属于本项目已支持的平台承诺。

## 更新验证顺序

1. 记录应用版本与 CPU 架构。
2. 执行只读诊断，确认协议、实例和认证可用。
3. 执行全部单元测试。
4. 在独立任务目录完成真实任务、取消与文件结果验收。
5. 更新本表并保留脱敏测试报告后，才声明支持该版本。
